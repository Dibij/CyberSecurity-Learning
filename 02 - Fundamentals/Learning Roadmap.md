# Learning Roadmap

> This is a list of skills I want to acquire, not a deadline.
> I mark a topic complete when I can demonstrate its learning goal.

## Phase 1: Foundations

### Networking

- [ ] [[DNS]] — Explain how domain names are resolved to IP addresses.
- [ ] [[IP Addresses]] — Explain IP addresses and distinguish private from public addresses.
- [ ] [[Ports and Sockets]] — Explain ports and how they relate to network connections.
- [ ] [[TCP and UDP]] — Explain their basic differences.
- [ ] [[Routing and NAT]] — Explain how traffic travels between networks.
- [ ] [[HTTP Fundamentals]] — Explain requests, responses, methods, and status codes.
- [ ] [[HTTPS and TLS]] — Explain what HTTPS adds to HTTP.

### Linux

- [ ] [[Linux Fundamentals]] — Navigate the filesystem and manage files independently.
- [ ] [[Users and Permissions]] — Explain users, groups, and file permissions.
- [ ] [[Processes and Services]] — Inspect running processes and services.
- [ ] [[Linux Networking Commands]] — Inspect network interfaces and connections.

### Web Fundamentals

- [ ] [[HTML Forms]] — Explain how browser forms submit data.
- [ ] [[Cookies and Sessions]] — Explain how websites maintain user sessions.
- [ ] [[Authentication and Authorization]] — Explain the difference between identity and permissions.
- [ ] [[APIs and JSON]] — Inspect a basic API request and response.

## Phase 2: Web Security

- [ ] [[SQL Injection]] — Explain the underlying vulnerability and complete a beginner lab.
- [ ] [[Cross-Site Scripting]] — Explain the vulnerability and complete a beginner lab.
- [ ] [[Authentication Vulnerabilities]] — Recognize common authentication weaknesses.
- [ ] [[Access Control]] — Identify and test authorization boundaries in a practice lab.
- [ ] [[File Upload Vulnerabilities]] — Understand common risks associated with file uploads.

## Phase 3: Tools and Practical Testing

- [ ] [[Nmap]] — Interpret a basic scan against my own machine or an authorized lab.
- [ ] [[Burp Suite]] — Intercept and inspect HTTP requests in a practice environment.
- [ ] [[Browser Developer Tools]] — Inspect requests, responses, and browser storage.
- [ ] [[PortSwigger Labs]] — Complete and document beginner web security exercises.
- [ ] [[OverTheWire Bandit]] — Solve beginner Linux challenges independently.

## Phase 4: Projects

- [ ] [[Secure a Personal Project]] — Review one of my own applications for security weaknesses.
- [ ] [[Secure a Personal Server]] — Review the configuration and access controls of a server I operate.
- [ ] [[Write a Security Report]] — Document a finding, its impact, evidence, and remediation.
- [ ] [[Independent Lab Assessment]] — Assess an authorized practice target and document the results.

## Completion Criteria

Before checking a topic off, ask:

- [ ] Can I explain the concept without copying a source?
- [ ] Can I describe how it works?
- [ ] Can I answer the important questions I generated?
- [ ] Have I performed a practical observation or exercise where appropriate?
- [ ] Can I identify something I still do not know?

A topic can be marked complete at a beginner level.
I can revisit it later as my understanding improves.
