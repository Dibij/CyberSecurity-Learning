# Projects Directory

This directory stores documentation and deliverables for hands-on cybersecurity projects.

## Project Ideas & Future Work
- **Server Hardening:** Step-by-step security hardening of a personal Linux VPS (SSH keys, UFW firewall, fail2ban).
- **Home Lab Setup:** Setting up a practice environment (Docker, vulnerable web apps, pfSense / network segmentation).
- **Security Audit / Code Review:** Conducting a static and dynamic analysis of your own applications.
- **Security Report:** Writing professional vulnerability findings with reproducible proof-of-concepts and remediation recommendations.
